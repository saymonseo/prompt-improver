Предлагаю на неделю одно изменение: **после ужина записывать на бумаге одно главное дело на завтра**. Достаточно одной короткой строки и не больше двух минут. Ужин служит привязкой к привычному событию; точное время выбирать не требуется. В эксперименте меняется только это действие.

Отмечайте выполнение: «да» — записали, «нет» — пропустили. После пропуска продолжайте следующим вечером после ужина: догонять и начинать неделю заново не нужно.

Заполняйте дневник семь дней подряд. Выполнение отмечайте вечером, остальные поля — следующим утром. Каждая строка относится к одному вечеру и следующему за ним утру.

| День | Действие: да/нет | Отход ко сну | Подъём следующим утром | Состояние утром, 1–5 | Необычные обстоятельства |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |
| 2 |  |  |  |  |  |
| 3 |  |  |  |  |  |
| 4 |  |  |  |  |  |
| 5 |  |  |  |  |  |
| 6 |  |  |  |  |  |
| 7 |  |  |  |  |  |

Для заполнения:

- **Отход ко сну** — время, когда легли с намерением спать. Это не время фактического засыпания. По разнице между отходом ко сну и подъёмом длительность сна здесь не рассчитываем.
- **Состояние утром:** 1 — очень тяжело, совсем нет бодрости; 3 — среднее; 5 — бодро, чувствую себя отдохнувшим.
- **Необычные обстоятельства:** коротко укажите, например, позднюю работу, гостей или шум. Если ничего необычного не было, напишите «не было».
- Если значение неизвестно или вы не помните, пишите **«нет данных»**, а не ноль.

После седьмой ночи выделите пять минут на итоги:

1. **Выполнимость.** Посчитайте отметки «да», «нет» и «нет данных» отдельно. Мой предложенный ориентир — действие выполнено хотя бы в 5 из 7 вечеров и не создавало заметных неудобств.
2. **Наблюдения.** Посмотрите, различались ли время отхода ко сну и утренние оценки в начале и конце недели. Отдельно запишите, помогала ли вечерняя строка организовать следующий день. Учитывайте необычные обстоятельства.
3. **Решение.** Если действие удобно и кажется полезным, можно продолжить ещё неделю. Если часто забывалось — пересмотреть привязку; если мешало — отказаться.

Эта неделя даст первые наблюдения. Они не показывают улучшение относительно неизвестного прежнего уровня, а совпадение изменений с новой привычкой ещё не доказывает причинную связь.
