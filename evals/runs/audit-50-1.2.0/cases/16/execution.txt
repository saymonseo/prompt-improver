1. Начать разговор можно такими фразами, адаптируя их под себя:

   «Мне кажется, что уборка чаще оказывается на мне. Это моё ощущение: мы пока не составляли общий список, и я могу не учитывать часть дел».

   «Мы оба работаем. Мне хочется договориться о домашних делах на одну неделю, а потом обсудить, насколько это удобно каждому».

   «Как ты видишь ситуацию? Какие дела ты берёшь на себя сейчас и что предлагаешь учесть?»

   «Сейчас удобно поговорить? Если нет, давай выберем время».

2. Предложите вместе составить список и обсудить недельный вариант распределения.

   Сначала каждый называет домашние дела, которые считает нужным включить. Запишите предложения обоих. Если для каких-то дел нужны подготовка или организация, их тоже можно включить. На этом этапе достаточно собрать общую картину.

   Затем по каждому делу обсудите: нужно ли оно на этой неделе, как часто или к какому сроку, какой результат будет достаточным для обоих. Если ожидания различаются, попробуйте согласовать конкретный вариант на неделю.

   После этого каждый рассказывает о доступном времени, другой нагрузке и предпочтениях. На этой основе обсудите, кто готов взять каждое дело. Справедливое распределение не обязательно означает одинаковое число пунктов: дела могут требовать разного времени и усилий.

   Для записи можно использовать такую форму:

   | Дело | Кто берёт на себя | Срок или частота | Что считается выполненным |
   |---|---|---|---|
   |  |  |  |  |
   |  |  |  |  |
   |  |  |  |  |

   Перед началом недели перечитайте запись вместе: «Всё ли здесь понятно и посильно каждому? Есть ли пункты, с которыми кто-то пока не согласен?» Спорные пункты оставьте открытыми до согласования. Можно также предложить порядок на случай изменений: «Если кто-то понимает, что не успевает, давай сообщать об этом и вместе решать, что перенести или перераспределить».

   Выберите дату проверки через неделю. Запись станет договорённостью, когда оба подтвердят, что согласны с ней.

3. Через неделю можно вернуться к записи с такими вопросами:

   «Что из нашего плана получилось? Что помогло?»

   «Что оказалось неудобным или заняло больше сил и времени, чем ожидалось?»

   «Как каждый из нас оценивает свою нагрузку за эту неделю?»

   «Одинаково ли мы понимали, что считается выполненным? Какие дела не попали в список?»

   «Что нам удобно сохранить, а что хочется изменить на следующую неделю?»

   По итогам можно вместе обновить сроки, частоту, ожидаемый результат и распределение дел, подтвердив согласие обоих.
