1. **Описание MVP**

Приложение для Android помогает одному человеку вести простой дневник привычек: создать до пяти привычек и вручную отмечать их выполнение по дням.

Основные возможности: добавление привычки, просмотр списка за выбранный день, установка и снятие отметки выполнения. Названия привычек и отметки сохраняются только на устройстве. Интернет для работы не требуется.

**Допущения, предлагаемые для первой версии:**

- У привычки есть только название; оно не может быть пустым.
- Все привычки отслеживаются ежедневно, без настройки расписания.
- При открытии показывается сегодняшний день по дате устройства. Можно выбрать прошлый день, чтобы посмотреть или исправить отметки. Будущие дни недоступны.
- Для каждой привычки за день возможна одна отметка «Выполнено». Отсутствие отметки означает только, что выполнение не отмечено.
- Отметку можно снять, чтобы исправить ошибочное нажатие.

В первую версию не входят напоминания, аккаунты, платные подписки, статистика, серии успешных дней, обмен данными и облачная синхронизация. Переименование и удаление привычек также пока не включены. Данные приложения не должны попадать в облачные резервные копии. Восстановление после удаления приложения или потери устройства не предусмотрено.

2. **Три основных пользовательских сценария**

**Сценарий 1. Добавить привычку**  
**Цель:** начать отслеживать новое действие.  
**Действия:** пользователь открывает список, выбирает добавление привычки, вводит название и сохраняет.  
**Результат:** привычка появляется в списке без отметки за сегодня. Если уже добавлены пять привычек, приложение сообщает о пределе и не создаёт шестую.

**Сценарий 2. Отметить выполнение и исправить ошибку**  
**Цель:** записать выполнение привычки за нужный день.  
**Действия:** пользователь оставляет сегодняшний день или выбирает прошлый, нажимает на отметку рядом с привычкой. При ошибке нажимает повторно.  
**Результат:** отметка появляется или снимается только у выбранной привычки за выбранный день.

**Сценарий 3. Вернуться к сохранённым записям**  
**Цель:** посмотреть ранее отмеченное выполнение.  
**Действия:** пользователь закрывает приложение, открывает его снова и выбирает день, за который делал отметки.  
**Результат:** список привычек и отметки за этот день соответствуют последним сохранённым действиям.

3. **Проверяемые критерии приёмки**

Ниже описаны будущие проверки; испытания ещё не проводились.

- При последовательном добавлении пяти привычек все пять должны появиться в списке. Попытка добавить шестую должна показать понятное сообщение о пределе, сохранив существующие записи.
- Пустое название или название только из пробелов не должно сохраняться.
- Нажатие должно устанавливать отметку за выбранный день; повторное нажатие — снимать её. Остальные привычки и дни не должны изменяться.
- Без ручного действия отметки не должны появляться автоматически.
- При открытии должен отображаться сегодняшний день. Прошлые дни должны быть доступны для просмотра и исправления, будущие — недоступны.
- После полного закрытия и повторного открытия приложения названия, установленные и снятые отметки должны сохраняться.
- Все основные действия должны работать в авиарежиме. Отдельная проверка передачи данных и резервного копирования должна подтвердить, что данные остаются только на устройстве.
- Приложение не должно создавать напоминания, запрашивать регистрацию или вход, предлагать подписку либо требовать оплату функций MVP.
