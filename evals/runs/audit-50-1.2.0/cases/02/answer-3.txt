Подготовь описание MVP — минимальной первой версии приложения для отслеживания привычек на Android. Сейчас нужен только текст требований. Все личные обстоятельства в задании учебные.

Исходные данные и ограничения:
- Приложение предназначено для личного использования.
- Можно отслеживать не более пяти привычек.
- Основная функция — ручные отметки выполнения привычек по дням.
- Напоминания в первую версию не входят.
- Данные должны храниться только на устройстве.
- Аккаунты и платные подписки не нужны.
- У пользователя нет навыков программирования.
- Остальные сведения пока неизвестны.

Подготовь результат без уточняющих вопросов. Не пиши код, не выполняй разработку и не выбирай платный сервис. Объясняй простым языком. Не расширяй первую версию дополнительными функциями без обоснованной необходимости. Если для связного описания потребуется выбрать неуказанное поведение, предложи простой вариант и явно обозначь его как допущение, а не как согласованное требование.

Формат ответа:
1. Описание MVP: назначение, основные возможности и границы первой версии.
2. Ровно три основных пользовательских сценария. Для каждого укажи цель пользователя, последовательность действий и наблюдаемый результат.
3. Проверяемые критерии приёмки: конкретные условия и ожидаемое поведение приложения. Обязательно охвати предел в пять привычек, ручные отметки по дням, сохранение данных после закрытия и повторного открытия, хранение только на устройстве, отсутствие напоминаний, аккаунтов и платных подписок.

Согласуй сценарии и критерии с описанием MVP. Критерии должны описывать будущую проверку, а не изображать уже выполненные испытания.

Ответ — на русском языке, не более 500 слов.
