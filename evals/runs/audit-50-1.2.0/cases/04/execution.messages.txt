Функция использует `strip()` для обрезки пробельных символов и `casefold()` для сравнения без учёта регистра. В результат попадает первое написание после обрезки.

```python
def clean_strings(strings: list[str]) -> list[str]:
    result = []
    seen = set()

    for value in strings:
        trimmed = value.strip()
        if not trimmed:
            continue

        key = trimmed.casefold()
        if key not in seen:
            seen.add(key)
            result.append(trimmed)

    return result
```

Применение к исходному списку:

```python
values = [" молоко ", "Хлеб", "молоко", "", "ХЛЕБ", "Яблоки"]
result = clean_strings(values)
```

Результат:

```python
["молоко", "Хлеб", "Яблоки"]
```

Ровно два пограничных примера:

1. **Только пустые и пробельные строки.**

   Вход:
   ```python
   ["", " ", "\t", "\n", " \t\n "]
   ```
   Ожидаемый результат:
   ```python
   []
   ```

2. **Разнесённые дубликаты с разным регистром и пробелами по краям.**

   Вход:
   ```python
   [" Кот ", "Пёс", "КОТ", " Рыба ", " пЁс ", "рыБА", "кот "]
   ```
   Ожидаемый результат:
   ```python
   ["Кот", "Пёс", "Рыба"]
   ```
