```text
Напиши функцию на Python, которая принимает список строк и возвращает список, обработанный по следующим правилам:

1. Удаляет пробельные символы по краям каждой строки.
2. Исключает строки, ставшие пустыми после обрезки.
3. Удаляет дубликаты без учёта регистра.
4. Сохраняет первое встретившееся написание каждой уникальной строки после обрезки, включая его регистр.
5. Сохраняет исходный порядок оставшихся элементов.

Исходный список:
[" молоко ", "Хлеб", "молоко", "", "ХЛЕБ", "Яблоки"]

Используй Python без внешних библиотек. Входные элементы — строки; обработка других типов не требуется. Никаких файловых или сетевых операций: весь результат представь текстом в ответе.

Выдай:
- Код функции.
- Результат её применения к исходному списку.
- Ровно два полезных пограничных примера с входом и ожидаемым результатом: список только из пустых и пробельных строк; список с разнесёнными дубликатами, различающимися регистром и пробелами по краям.

Проверь согласованность кода и показанных результатов. Если код не запускался, не утверждай, что он прошёл тестирование.

Ответ — на русском языке, до 500 слов, без уточняющих вопросов.
```
