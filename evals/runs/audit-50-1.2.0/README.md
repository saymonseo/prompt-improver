# Материалы аудита Prompt Improver 1.2.0 на 50 темах

[Полный отчёт с таблицей всех тем](../../AUDIT-50-2026-09-06.md) содержит оценки, разбор замечаний и рекомендации. Здесь опубликованы фактические входы и результаты модельных запусков.

- [Методика и ограничения](PROTOCOL.md), [шкала оценивания](rubric.md), [версия и среда](manifest.json).
- [Условия выбранных 50 случаев](cases.json), [первоначальные условия](fixtures-original.json), [использованная спецификация](SPECIFICATION.md), [общие обёртки](harness.json).
- [Оценки JSON](scorecard.json), [таблица CSV](scorecard.csv), [сводные числа](summary.json), [разбор основного агента](adjudication.json), [расхождения A/B](grade-differences.json).
- [Формат, длина и цитаты](inspection.json), [арифметика и расписание клуба](deterministic-checks.json), [исполнение Python](python-execution-check.json), [учебное расписание](schedule30-check.json), [проверка источников](source-checks.json), [метаданные запусков](run-metrics.json).
- [Исправление случая 40](case40-correction.json), [исключённый исходный диалог](excluded-attempts/40/dialogue.json), [исключённое исполнение](excluded-attempts/40/execution.txt).

В папках `cases/01`–`cases/50` находятся диалоги, отдельные реплики, итоговые промпты, ответы исполнителей и метаданные. В `reviews/` сохранены входы и результаты двадцати сеансов оценивания. Ссылки на каждый выбранный промпт и ответ находятся в таблице полного отчёта.

`summary.json` отражает исходные замечания оценщиков, включая замечания к самому тесту. Для окончательной интерпретации нужен `adjudication.json`; исходные оценки не переписаны.

Проверка опубликованных материалов без вызова модели:

```bash
python evals/runs/audit-50-1.2.0/verify_public.py
```

[Скрипт проверки](verify_public.py) восстанавливает входы улучшателя, сверяет ответы и проверяет наличие двух полных оцениваний. Повторное выполнение модели не обязано дать идентичные ответы.
